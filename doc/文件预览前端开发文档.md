## 1. 旧接口下线说明（必读）

以下接口**已从后端删除**，前端必须同步改造，否则运行时报 404：

| 已删除 | 替代 |
| --- | --- |
| `GET /sys/files/preview?fileStorageKey=` | `POST /sys/files/preview/init` + `GET /sys/files/preview/content?previewId=` |
| `GET /sys/files/download/{fileStorageKey}` | `GET /sys/files/preview/download?previewId=` |
| `GET /sys/files/preview/init?fileStorageKey=`（GET 版） | `POST /sys/files/preview/init`（JSON body） |

`POST /sys/files/upload`、`POST /sys/files/chunk/*` 保留不变。

## 2. 通用约定

### 2.1 响应结构

所有 JSON 接口统一返回 `R<T>`：

```json
{
  "code": 200,
  "msg": "成功！",
  "data": {},
  "dataType": "OBJECT",
  "traceId": "a1b2c3d4"
}
```

- **成功判断只认 `code === 200`**；业务异常（如 50210 无权访问）返回的 **HTTP 状态码仍是 200**，错误信息在 `msg`，错误码在 `code`。
- 分页数据在 `data` 中：`{ current, size, pages, total, records }`，`current/size/pages/total` 是数字，`records` 是数组。

### 2.2 字段类型陷阱

后端 `Long` 统一序列化为**字符串**（防 JS 精度丢失），`Integer` 仍是数字：

| 字段 | JSON 类型 |
| --- | --- |
| `id`、`fileId`、`shareId`、`receiverId`、`userId`、`fileSize` | `string` |
| `receiverCount`、`accessCount`、`maxAccessCount`、`downloadCount`、`status`、`readStatus` | `number` |
| `expireAt`、`createTime`、`firstViewTime` | `string`（`yyyy-MM-dd HH:mm:ss`） |
| 枚举字段 | 数值或字符串字面量，见 2.3 |

> 前端类型定义一律用 `string` 接 ID，不要写 `number`，否则 `Number` 转换会截断。

### 2.3 枚举取值（JSON 实际返回）

| 枚举 | 取值 |
| --- | --- |
| `initStatus` | `0` 成功 / `1` 转换中 / `2` 不支持预览 / `3` 转换失败 / `4` 仅下载 |
| `previewMode` | `image` / `pdf` / `video` / `audio` / `text` / `json` / `other` |
| `previewSource` | `original` / `convert` |
| `accessScope` | `private` / `public` |
| `shareMode` | `LINK` / `USER` |
| `permission` | `VIEW` / `VIEW_DOWNLOAD` / `DOWNLOAD` |
| `watermark.level` | `off` / `l1` / `l2` |
| `conversion.status` | `NONE` / `PENDING` / `PROCESSING` / `SUCCESS` / `FAILED` |

### 2.4 鉴权

- 业务接口沿用现有 `Authorization: Bearer <token>` 拦截器，无需改动。
- 预览四个接口（`init` / `status` / `content` / `download`）与链接分享的 `meta` / `open` 后端已放开匿名访问；**登录状态仍会被解析**（带 token 就按登录用户判权）。
- `content` / `download` 的访问凭证是 **`previewId` 本身**，所以 `<img src>`、`<video src>` 可以直接用，不需要额外加 header；PDF 建议用 `axios responseType: 'blob'` + pdf.js 渲染（见 4.4）。

## 4. 预览主链路

### 4.1 时序

```
用户点击文件名
  → POST /sys/files/preview/init      （拿 previewId + 能力 + 转换状态）
  → initStatus === 1 ? 轮询 GET /sys/files/preview/status : 继续
  → capabilities.preview === true
        → GET /sys/files/preview/content?previewId=   （按 previewMode 渲染）
  → 用户点下载
        → capabilities.download === true ? GET /sys/files/preview/download?previewId=
```

### 4.2 初始化

`POST /sys/files/preview/init`

请求体（`fileId` 与 `fileStorageKey` 二选一，优先 `fileId`）：

```json
{
  "fileId": "2118538699246489601",
  "fileStorageKey": null,
  "shareTicket": null
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `fileId` | string | 二选一 | 推荐 |
| `fileStorageKey` | string | 二选一 | 兼容老数据 |
| `shareTicket` | string | 否 | 分享访问时传；传了则忽略文件定位参数 |

响应 `data`：

```json
{
  "previewId": "pv_9f2c1b7e4a5d4c0e9b3a1f6d2c8e7a10",
  "initStatus": 0,
  "fileName": "2026年度经营分析.docx",
  "fileOriginalName": "2026年度经营分析.docx",
  "fileSize": "204800",
  "fileSizeInfo": "200 KB",
  "fileSuffix": "docx",
  "fileType": "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
  "accessScope": "private",
  "previewMode": "pdf",
  "previewSource": "convert",
  "capabilities": { "preview": true, "download": true, "print": true, "share": true },
  "conversion": {
    "required": true,
    "status": "PROCESSING",
    "progress": 50,
    "message": "正在转换",
    "retryAfterMs": 1000
  },
  "watermark": { "enabled": true, "level": "l1", "text": "张三(1001) 2026-11-09 16:20 禁止外传", "opacity": 0.1 },
  "urls": {
    "previewUrl": "/sys/files/preview/content?previewId=pv_xxx",
    "downloadUrl": "/sys/files/preview/download?previewId=pv_xxx",
    "statusUrl": "/sys/files/preview/status?previewId=pv_xxx"
  },
  "expireAt": "2026-11-09 18:20:00"
}
```

前端处理规则：

1. `previewId` 必须落本地状态，后续 content / download / 创建分享都用它；**不要自己拼**，直接用 `urls`。
2. `capabilities.preview === false` 时不渲染预览区，按 `initStatus` 给提示：
   - `2` → 「该文件类型不支持在线预览，请下载查看」
   - `3` → 「文件转换失败，请下载查看」+ `conversion.message`
   - `4` → 「该文件仅支持下载」→ 直接调下载
3. `capabilities.download === false` 时隐藏下载按钮（分享 `VIEW`、合同类禁下都会是 false）。
4. `capabilities.share === false` 时隐藏「分享」入口（匿名、公开文件、分享来访者均为 false）。
5. `capabilities.print === false` 时隐藏打印按钮，同时给预览容器加 `no-print` class。
6. `expireAt` 是会话绝对过期时间；过期后所有接口返回 `50221`，此时重新走 `init` 即可，不要提示「文件不存在」。

### 4.3 转换轮询

`GET /sys/files/preview/status?previewId=`

响应 `data`：`{ previewId, initStatus, previewMode, previewSource, capabilities, conversion, watermark, expireAt }`（结构同初始化，少了文件基础信息）。

轮询规则：

| 项 | 建议值 |
| --- | --- |
| 触发条件 | `initStatus === 1` |
| 间隔 | 优先用 `conversion.retryAfterMs`（默认 1000ms），无值时 1s |
| 退避 | 前 5 次 1s，之后 2s，最长 3s |
| 上限 | 90s 或 60 次，超时提示「转换超时，请稍后重试或下载查看」 |
| 结束条件 | `initStatus` 变为 `0`（渲染）/ `3`（失败）/ `2`（不支持）/ `4`（仅下载） |
| 页面隐藏 | `document.hidden` 时暂停，可见后立即查一次 |

组件卸载、切换文件、弹窗关闭时必须清掉定时器并置空 `previewId`。

### 4.4 取预览内容

`GET /sys/files/preview/content?previewId=`

响应**不是统一 JSON**，按 `previewMode` 分三种：

| `previewMode` | Content-Type | 响应体 | 前端处理 |
| --- | --- | --- | --- |
| `text` | `application/json` | `TextPreviewVO`（见下） | 直接当 JSON 解析，追加文本 |
| `other` | `application/json` | `{ previewMode:"other", download:true, message:"..." }` | 提示并引导下载 |
| 其他（image/pdf/video/audio/json） | 文件真实 MIME | 二进制流 | `blob` 或直接 URL |

**文本分页（`text`）**

```json
{
  "content": "第一页正文……",
  "offset": 65536,
  "current": 1,
  "size": 65536,
  "pages": 12,
  "total": 786432,
  "hasMore": true,
  "charset": "UTF-8"
}
```

| 请求参数 | 说明 |
| --- | --- |
| `previewId` | 必填 |
| `offset` | 上一页返回的 `offset`，续读时**原样回传**，优先于 `pageNo` |
| `pageNo` | 页码，从 1 开始；仅在不传 `offset` 时生效 |
| `size` | 单页字节数，默认 65536，取值 4096~262144 |
| `charset` | 首屏不传由服务端探测；拿到返回值后**后续请求回传**，避免重复探测 |

前端交互：滚动到底或点「下一页」时带 `offset` 追加；`hasMore === false` 显示「已到末尾」。大文本不要一次性渲染全部，用虚拟滚动或分段折叠。

**二进制内容**

- 图片：`<img :src="urls.previewUrl">` 可直接用（凭证在 URL 里）。
- 视频/音频：`<video :src>` / `<audio :src>` 直接可用，拖动进度依赖后端 Range（已支持 206）。
- PDF：**不要用 `<iframe>`**。后端未关闭 `X-Frame-Options`（Spring Security 默认 `DENY`），iframe 会被浏览器拦截。正确做法：

```ts
const { data } = await request.get(urls.previewUrl, { responseType: 'blob' })
const blobUrl = URL.createObjectURL(new Blob([data], { type: 'application/pdf' }))
await pdfjsLib.getDocument({ url: blobUrl }).promise
// 组件卸载时 URL.revokeObjectURL(blobUrl)
```

- JSON 类型：后端原样输出 `application/json`，可直接 `responseType: 'text'` 后做格式化高亮。

### 4.5 下载

`GET /sys/files/preview/download?previewId=`

- 返回**原始文件**（不是转换产物），`Content-Disposition: attachment`，文件名取原始名。
- 前端用 `window.open(url)` 或 `a[download]` 均可；带 token 的 axios 方式也可以（`responseType: 'blob'` 后自行触发下载）。
- `capabilities.download === false` 调该接口会返回 `50210`。

### 4.6 L1 水印渲染

`watermark` 字段：

| 字段 | 说明 |
| --- | --- |
| `enabled` | 是否启用水印（`level !== 'off'` 且可预览） |
| `level` | `l1` 前端渲染 / `l2` 服务端已烧录 |
| `text` | 水印文案，如 `张三(1001) 2026-11-09 16:20 禁止外传` |
| `opacity` | 透明度，0.05~0.30 |

渲染规则：

- **`level === 'l1'`** → 前端在预览容器上平铺水印（CSS `::before` 或 canvas 生成 dataURL 背景），透明度用 `opacity`。
- **`level === 'l2'`** → 后端已把水印烧进 PDF/图片字节，**前端不要再叠加**，否则双重水印。
- `level === 'off'` → 不渲染。
- 水印层必须 `pointer-events: none`，不参与交互；容器设置 `user-select: none`（合同/文档类）。

参考实现：

```vue
<div class="preview-host" :class="{ 'no-print': !capabilities.print }">
  <div v-if="watermark.enabled && watermark.level === 'l1'" class="wm-layer"
       :style="{ backgroundImage: `url(${wmImage})`, opacity: watermark.opacity }" />
  <slot />
</div>
```

```ts
const wmImage = computed(() => {
  const canvas = document.createElement('canvas')
  canvas.width = 320
  canvas.height = 200
  const ctx = canvas.getContext('2d')!
  ctx.rotate(-Math.PI / 12)
  ctx.font = '14px sans-serif'
  ctx.fillStyle = '#999'
  ctx.fillText(watermark.text, 20, 100)
  return canvas.toDataURL('image/png')
})
```

### 4.7 打印限制

```css
@media print {
  .no-print { display: none !important; }
}
```

- `capabilities.print === false` 时不要只隐藏按钮，还要在打印样式里隐藏预览区或加水印提示。
- 该限制只能降低便利性，无法阻止系统截屏；需求口径是「溯源 + 降便利」，不要向前端承诺防截屏。

## 5. 分享

### 5.1 创建分享

`POST /sys/files/preview/share`（需登录，且 `capabilities.share === true`）

```json
{
  "previewId": "pv_xxx",
  "shareMode": "LINK",
  "permission": "VIEW_DOWNLOAD",
  "expireDays": 7,
  "requireCode": true,
  "accessCode": "",
  "maxAccessCount": 0,
  "receiverType": "USER",
  "receiverIds": [],
  "needNotice": false
}
```

| 参数 | 说明 |
| --- | --- |
| `previewId` | 必填，来自 init |
| `shareMode` | `LINK` 链接分享 / `USER` 指定用户 |
| `permission` | `VIEW` 仅看 / `VIEW_DOWNLOAD` 看+下 / `DOWNLOAD` 仅下载 |
| `expireDays` | 不传取用途默认；超上限会被**自动收敛**到 `share.max-expire-days` |
| `requireCode` | 不传取全局默认（链接默认 `true`，指定用户默认 `false`） |
| `accessCode` | `requireCode=true` 且为空时服务端随机 6 位 |
| `maxAccessCount` | 仅 `LINK` 生效，`0` 不限 |
| `receiverType` | `USER` / `DEPT` / `ROLE`（按创建时快照展开） |
| `receiverIds` | `USER` 模式必填；不能包含自己 |
| `needNotice` | 保留字段，当前版本不发站内信 |

响应 `data`：

```json
{
  "shareId": "2120000000000000101",
  "shareMode": "LINK",
  "permission": "VIEW_DOWNLOAD",
  "requireCode": true,
  "shareToken": "sh_8f3c...",
  "shareUrl": "/s/sh_8f3c...",
  "accessCode": "A1B2C3",
  "expireAt": "2026-11-16 16:20:00",
  "maxAccessCount": 0,
  "accessCount": 0,
  "receiverCount": 0,
  "status": 1,
  "fileName": "2026年度经营分析.docx",
  "fileSizeInfo": "200 KB",
  "fileSuffix": "docx",
  "createTime": "2026-11-09 16:20:00"
}
```

前端要点：

1. `accessCode` **只在创建响应返回一次**，必须立刻在弹窗里展示并提供「复制」，关闭后无法再查。
2. `shareUrl` 是站内相对路径，前端拼上 `location.origin` 生成完整链接。
3. `USER` 模式不返回 `shareToken` / `shareUrl` / `accessCode`（即使设置了提取码，也不回显）。
4. 创建前先根据 `permission` 判断：`permission` 含下载但 `capabilities.download === false` → 禁用「可下载」选项并提示「该文件不允许下载」。
5. 文件不支持预览（`initStatus === 2`）时只允许选 `DOWNLOAD`，否则后端返回 `400` 提示。

### 5.2 创建弹窗字段

| 字段 | 控件 | 规则 |
| --- | --- | --- |
| 分享方式 | Radio | 链接分享 / 指定用户 |
| 权限 | Radio | 仅查看 / 查看+下载 / 仅下载；按 `capabilities` 禁用非法项 |
| 有效期 | InputNumber + 快捷项（1/7/15/30 天） | 1~30，默认取后端建议值（可先写 7） |
| 提取码 | Switch + Input | 开启后可留空（随机）；自定义需 4~8 位字母数字，4~5 位必须字母+数字混排 |
| 访问上限 | InputNumber（仅链接分享） | 0 = 不限 |
| 接收人 | 用户选择器（仅指定用户） | 支持用户/部门/角色，去重，上限 500，禁选自己 |
| 发送通知 | Switch（仅指定用户） | 当前版本不生效，可先隐藏 |

提取码前端校验（与后端一致）：

```ts
const validateCode = (v: string) => {
  if (!/^[A-Za-z0-9]{4,8}$/.test(v)) return '提取码必须为 4~8 位字母数字'
  if (/^(.)\1+$/.test(v)) return '提取码不能为重复字符'
  if (v.length < 6 && (!/[A-Za-z]/.test(v) || !/\d/.test(v))) return '4~5 位提取码必须同时包含字母和数字'
  return ''
}
```

### 5.3 链接分享访问页 `/s/:token`

```
GET  /sys/files/share/link/{token}/meta    → 展示文件信息 + 是否需要提取码
POST /sys/files/share/link/{token}/open    → { accessCode? } → shareTicket
POST /sys/files/preview/init               → { shareTicket } → previewId
GET  /sys/files/preview/content?previewId=
```

`meta` 响应：

```json
{
  "shareId": "2120000000000000101",
  "shareMode": "LINK",
  "fileName": "2026年度经营分析.docx",
  "fileSizeInfo": "200 KB",
  "fileSuffix": "docx",
  "creatorName": "张三",
  "permission": "VIEW",
  "requireCode": true,
  "expireAt": "2026-11-16 16:20:00",
  "status": 1
}
```

页面逻辑：

1. 先调 `meta`；`status !== 1` 或过期 → 展示「分享已失效」，不再展示文件名等敏感信息之外的按钮。
2. `requireCode === true` → 显示提取码输入框；`false` → 直接调 `open`（body 传 `{}` 或省略）。
3. `open` 成功拿 `shareTicket`，**存在内存/sessionStorage**，不要放 URL。
4. `open` 返回 `permission === 'DOWNLOAD'` 时，不进入预览，直接调下载（需先 init 拿 `previewId`，此时 `initStatus = 4`）。
5. 提取码错误 `50226`、锁定 `50227` 分别提示；不要区分「分享不存在」和「提取码错误」的具体原因以外信息。
6. 页面禁止被搜索引擎索引（`<meta name="robots" content="noindex">`）。

### 5.4 指定用户分享 `/share/user/:shareId`

```
GET  /sys/files/share/user/{shareId}/meta   （需登录 + 是接收人）
POST /sys/files/share/user/{shareId}/open   （需登录，body { accessCode? }）
```

- 非接收人访问 → `50231`，提示「该分享未授权给你」并跳回分享中心。
- 打开成功会自动置为已读并记录 `firstViewTime`，成功后刷新未读角标。
- 分享中心点「打开」直接跳这个路由；如果接收人已读，仍可再次打开。

### 5.5 分享中心

**我分享的** `POST /sys/files/share/page`

```json
{ "current": 1, "size": 10, "shareMode": "LINK", "permission": "VIEW", "status": 1,
  "startTime": "2026-11-01 00:00:00", "endTime": "2026-11-30 23:59:59" }
```

> `fileName` 关键字**当前未生效**（后端未实现模糊匹配），前端可以隐藏该搜索项。若要保留，请只做本地筛选。

列表列：文件名、分享方式、权限、接收范围、访问次数、有效期、状态、创建时间、操作。

操作按权限与状态显隐：

| 操作 | 条件 | 接口 |
| --- | --- | --- |
| 复制链接 | `shareMode === 'LINK'` 且 `status === 1` | 用 `shareUrl` 拼绝对地址 |
| 重置提取码 | `requireCode === true` 且 `status === 1` | `POST /sys/files/share/{shareId}/reset-code?accessCode=` |
| 查看接收人 | `shareMode === 'USER'` | `GET /sys/files/share/{shareId}/receivers` |
| 撤销 | `status === 1` | `DELETE /sys/files/share/{shareId}` |

`reset-code` 返回新提取码明文（`data` 为字符串），同样只展示一次。

**分享给我的** `POST /sys/files/share/received/page`

```json
{ "current": 1, "size": 10, "readStatus": 0, "includeInvalid": false }
```

响应记录：

```json
{
  "receiverId": "2120000000000000201",
  "shareId": "2120000000000000102",
  "fileName": "合同扫描件.pdf",
  "fileSizeInfo": "1.2 MB",
  "fileSuffix": "pdf",
  "creatorName": "李四",
  "permission": "VIEW",
  "readStatus": 0,
  "firstViewTime": null,
  "expireAt": "2026-11-16 16:20:00",
  "status": 1
}
```

- 未读角标：`GET /sys/files/share/received/unread-count`，`data` 是 **字符串**（后端 `Long` 统一转字符串），前端 `Number(data)` 后再展示。
- 标记已读：`POST /sys/files/share/{shareId}/read`（打开时后端已自动置读，此接口用于「全部已读」）。
- 从列表移除：`POST /sys/files/share/{shareId}/hide`（只影响列表，不影响链接有效性）。

状态展示映射：

| `status` | 展示 | 是否可打开 |
| --- | --- | --- |
| `1` 且未过期 | 正常 | 是 |
| `1` 但 `expireAt` 已过 | 已过期（灰） | 否，提示 50225 |
| `0` | 已撤销 | 否 |
| `2` | 已失效 | 否 |

### 6.1 文件用途管理

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/sys/files/used/list` | GET | 启用用途（上传页下拉用，所有登录用户可调） |
| `/sys/files/used/page` | POST | 用途分页（管理员），body `{"current":1,"size":10}` |
| `/sys/files/used/get/{id}` | GET | 用途详情（管理员），用于编辑回显 |
| `/sys/files/used/create` | POST | 新增 |
| `/sys/files/used/update/{id}` | POST | 修改，`usedCode` 不可改 |
| `/sys/files/used/disable/{id}` | POST | 停用 |
| `/sys/files/used/remove/{id}` | POST | 删除（仅内置=0 且无引用） |

分页查询字段（`SysFileUsedQuery`，继承 `PageBasicQuery`，分页固定 `current` / `size`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `usedCode` | string | 用途编码，模糊匹配 |
| `usedName` | string | 用途名称，模糊匹配 |
| `enabled` | number | 1 启用 / 0 停用，精确匹配 |
| `builtIn` | number | 1 内置 / 0 自定义，精确匹配 |

返回 `PageResponse`：`total` / `current` / `size` / `pages` 为**字符串**（后端 `Long` 统一转字符串），`records` 为用途数组。详情 `get/{id}` 返回单条用途对象。

表单字段（`SysFileUsedForm`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `usedCode` | string | 编码，`^[a-z][a-z0-9_]{1,31}$`，创建后只读 |
| `usedName` | string | 名称 |
| `description` | string | 说明 |
| `enabled` | number | 1 启用 / 0 停用 |
| `sort` | number | 排序 |
| `accessScope` | `private`/`public` | 默认访问范围 |
| `publicAllowed` | number | 是否允许设为公开（0/1） |
| `downloadAllowed` | number | 下载闸门 |
| `printAllowed` | number | 打印闸门 |
| `shareAllowed` | number | 分享闸门 |
| `shareExpireDays` | number | 默认分享天数，空则继承全局 |
| `shareMaxAccessCount` | number | 分享访问上限，空则继承全局 |

列表额外返回 `builtIn`（1 = 内置不可删）与 `fileCount`（引用文件数）。

交互：

- 内置用途：删除按钮禁用，`usedCode` 只读。
- 有引用的用途：删除返回错误提示，引导「停用」。
- 关闭 `publicAllowed` 属高风险操作，二次确认并提示「该用途下公开文件将不再允许匿名访问」。

### 6.2 文件全局配置

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/sys/files/settings?group=share` | GET | 按分组取配置 |
| `/sys/files/settings` | PUT | 批量保存 `{ items: [{ key, value, version }] }` |
| `/sys/files/settings/reset` | POST | 恢复默认，body 为 key 数组 |

配置项结构：

```json
{
  "settingKey": "share.default-expire-days",
  "settingValue": "7",
  "valueType": "int",
  "settingGroup": "share",
  "settingName": "默认分享有效期（天）",
  "description": "...",
  "defaultValue": "7",
  "minValue": "1",
  "maxValue": "30",
  "userOverridable": 1,
  "overrideDirection": "TIGHTEN_ONLY",
  "overrideMin": null,
  "overrideMax": null,
  "overrideOptions": null,
  "overrideHint": null,
  "version": 0
}
```

页面按 `settingGroup` 分页签：

| group | 含义 | 代表 key |
| --- | --- | --- |
| `download` | 下载策略 | `download.default-allow`、`download.owner-override`、`download.anonymous-public`、`download.public-logged-in` |
| `print` | 打印策略 | `print.default-allow` |
| `share` | 分享策略 | `share.enabled`、`share.default-expire-days`、`share.max-expire-days`、`share.link.require-code-default`、`share.user.require-code-default`、`share.link.no-code-max-expire-days`、`share.receiver.max-count`、`share.code.min-length`、`share.code.max-length`、`share.code.random-length`、`share.code.fail-limit`、`share.code.lock-minutes` |
| `watermark` | 水印 | `watermark.default-level`、`watermark.opacity`、`watermark.text-template`、`watermark.cache-minutes`、`watermark.degrade-threshold` |
| `convert` | 转换与清理 | `convert.enabled`、`convert.retention-days`、`convert.share-buffer-days`、`convert.max-retention-days`、`convert.max-file-size-mb`、`convert.timeout-seconds`、`convert.max-retry`、`convert.queue-capacity` |
| `session` | 会话 | `preview.session.ttl-minutes`、`preview.session.max-hours`、`preview.anonymous.ttl-minutes` |
| `image` | 图片 | `image.default-mode` |
| `file` | 其他 | `file.default-used` |

渲染规则：

- `valueType === 'bool'` → Switch；`int` → InputNumber（`minValue`/`maxValue`）；`string` → Input。
- 保存时必须回传 `version`（乐观锁），版本冲突后端会拒绝，提示「配置已被他人修改，请刷新后重试」。
- `userOverridable` / `overrideDirection` 当前只读展示（后端已支持字段，但**没有前端写入入口对应的接口语义**，本期仅在用途/全局层配置）。若要展示，放只读列即可，不要做编辑。

## 8. 请求封装

```ts
// api/file.ts
import request from '@/utils/request'

export const initPreview = (data: { fileId?: string; fileStorageKey?: string; shareTicket?: string }) =>
  request.post<PreviewInitResult>('/sys/files/preview/init', data)

export const getPreviewStatus = (previewId: string) =>
  request.get<PreviewStatusResult>('/sys/files/preview/status', { params: { previewId } })

export const getTextChunk = (previewId: string, params: { offset?: number; size?: number; charset?: string }) =>
  request.get<TextPreviewChunk>('/sys/files/preview/content', { params: { previewId, ...params } })

export const fetchPreviewBlob = (previewUrl: string) =>
  request.get(previewUrl, { responseType: 'blob' })

export const createShare = (data: ShareCreateParams) =>
  request.post<ShareInfo>('/sys/files/preview/share', data)

export const getLinkShareMeta = (token: string) =>
  request.get<ShareMeta>(`/sys/files/share/link/${token}/meta`)

export const openLinkShare = (token: string, accessCode?: string) =>
  request.post<ShareOpenResult>(`/sys/files/share/link/${token}/open`, { accessCode })
```

> `fetchPreviewBlob` 传的是后端返回的相对地址（已含 `previewId`），不要再拼 baseURL 前缀两次。

### 8.1 URL 前缀

`urls.*` 是服务端返回的**站内相对路径**（以 `/sys` 开头），方便直接放进 `axios({ url })`。

但如果项目通过 `baseURL` / vite proxy 暴露了额外前缀（如 `/api`），`<img :src>` / `<video :src>` 这类**浏览器原生请求**不会走 axios，需要自行补前缀：

```ts
const withPrefix = (path: string) => `${import.meta.env.VITE_API_PREFIX ?? ''}${path}`
```

建议全项目只用这一个函数处理 `urls.*`，避免 axios 与原生标签两套路径规则不一致。

## 9. 错误码与提示

| code | 含义 | 前端处理 |
| --- | --- | --- |
| 50206 | 文件不存在 | 「文件已删除」并关闭预览 |

| 50223 | 转换失败 | 展示 `conversion.message` + 下载按钮 |
| 50224 | 转换任务繁忙 | 提示稍后重试，可自动退避重试 1 次 |

| 50226 | 提取码错误 | 输入框标红，保留输入 |
| 50227 | 提取码错误次数过多 | 提示锁定，禁用提交按钮 10 分钟 |

| 50231 | 分享未授权给当前用户 | 跳回分享中心 |
| 50232 | 接收人超上限 | 提示最多 500 人 |
