# 文件模块字段长度清单

| 项 | 内容 |
| --- | --- |
| 数据库 | MySQL 8.0，库 `xht_platform`，字符集 `utf8mb4` |
| 数据来源 | `information_schema.COLUMNS` 实时导出，与当前库结构一致 |
| 覆盖表 | 7 张（`sys_file`、`sys_file_type`、`sys_file_used`、`sys_file_setting`、`sys_file_share`、`sys_file_share_receiver`、`sys_file_config_log`） |
| 字段总数 | 126 |
| 更新日期 | 2026-11-10 |

> 长度口径：`varchar/char` 为**字符数**（utf8mb4 下 1 字符最多占 4 字节，索引键上限 3072 字节）；`bigint/int/tinyint` 为**数字位数**；`datetime` 表示日期时间，不按字符计长；`text/json` 不按字符计长，标 `—`。
>
> 覆盖范围：文件模块 7 张表（当前库共 37 张表）。如需用户/角色/字典/日志等其余表，可再出一份全库版。

## 附录 B：关键长度约束（改动前必看）

| 字段 | 长度 | 说明 / 风险 |
| --- | --- | --- |
| `sys_file.file_original_name` | 200 字符 | 超长会被截断，完整名另存 `file_metadata.fullOriginalFilename` |
| `sys_file.file_storage_name` | 128 字符 | 实际落盘名（UUID + 后缀） |
| `sys_file.file_storage_key` | 64 字符 | 对外定位键，UUID 去掉横线为 32 位，留有余量 |
| `sys_file.file_storage_path` | 500 字符 | 相对路径 `xht/yyyy/MM/dd/uuid.ext` |
