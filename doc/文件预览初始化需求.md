## 1. 文档说明

### 1.1 目的

把现有 `/sys/files/preview/init` 从“返回文件基础信息”升级为“创建一次预览会话”：一次调用完成登录识别、文件归属与业务授权、预览类型识别、转换判定与会话创建，返回 `previewId`、文件信息、能力清单与转换状态。后续预览、下载、分享统一以 `previewId` 为凭证，不再直接暴露 `fileStorageKey`。

### 1.2 范围

本文覆盖：

- 预览初始化、状态查询、内容获取、下载；
- 公开文件与匿名访问；
- 分享（链接分享、指定用户分享、三态权限、可选提取码、分享中心、有效期、撤销）；
- 文件用途、后缀、全局、文件级四层配置；
- 转换（Office 转 PDF、图片按用途转 WebP/PDF）、异步轮询、产物生命周期；
- 打印限制、防截屏边界；
- 管理端配置页面与接口；
- 旧接口下线与数据迁移。

不覆盖：在线编辑、OCR、缩略图、多图合并 PDF、DRM/原生客户端、病毒扫描。

### 1.3 术语

| 术语 | 说明 |
| --- | --- |
| 预览会话 | 由 `previewId` 标识的一次访问上下文，绑定访问主体、文件、预览模式、转换产物 |
| `previewId` | 预览会话唯一标识，`pv_` + 32 位 UUID（去横线），不可枚举 |
| 能力 | `preview` / `download` / `print` / `share` 四个布尔值 |
| 访问主体 | `USER`（登录用户）、`ANON`（匿名公开访问）、`SHARE_LINK`（链接分享）、`SHARE_USER`（指定用户分享） |
| 转换产物 | Office/图片经转换后生成的 PDF/WebP 文件 |
| 权限授予（grant） | 主体是否具备查看/下载资格 |
| 配置闸门（gate） | 该用途/该文件是否允许下载/打印 |
| 分享模式 | `LINK`（链接分享）/ `USER`（指定用户分享） |
| 接收人 | 指定用户分享的站内用户，落在 `sys_file_share_receiver` |
| `requireCode` | 分享是否需要提取码；两种分享模式都适用 |
| 提取码 | 分享访问凭证，4~8 位字母数字，BCrypt 存储；可选 |
| `shareTicket` | 提取码校验通过或接收人校验通过后签发的短期访问票据 |

## 2. 背景与现状

### 2.1 现有能力

- 文件上传、分片上传、合并、下载、预览初始化、预览内容输出已收敛在 `SysFileController` 与 `ISysFileService`。
- 预览按 `sys_file_type` 的后缀映射分派到 `FilePreview` 实现：`text` 返回分页 JSON，`image/pdf/video/audio/json` 原样输出，`other` 返回下载提示。
- 权限校验框架为 `XhtFilePermissionContext` + `FilePermissionFilter` 链式过滤器。
- 文件用途为硬编码枚举 `FileUsedEnum`：`temp/avatar/notice/contract/document/other`。

### 2.2 现存问题

| --- | --- | --- | --- |

### 2.3 本次目标

1. 一次初始化完成鉴权、授权、类型识别、转换判定、会话创建。
2. 支持四种访问入口：登录用户、匿名公开文件、链接分享、指定用户分享。
3. 权限与配置分离：权限决定“能不能看”，权限 + 配置决定“能不能下”。
4. 用途、后缀、全局、文件级四层配置，管理端可配，用户只能收紧。
5. 转换异步化、可去重、可降级，产物有明确生命周期。
6. 分享支持链接/指定用户两种模式、三态权限、可选提取码、有效期、撤销与审计，并提供“我分享的 / 分享给我的”分享中心。
7. 打印可限制，明确防截屏边界。
8. 下线旧预览/下载接口，收敛到 `previewId`。

### 2.4 非目标

在线编辑、OCR、缩略图、多图合并 PDF、DRM/原生客户端、病毒扫描、跨租户资源共享。

## 3. 总体设计

### 3.1 核心思路

```
初始化请求
  -> 识别访问主体（登录 / 匿名公开 / 链接分享票据 / 指定用户分享票据）
  -> 定位文件并校验查看权限
  -> 读取四层配置，计算预览模式、下载/打印/分享能力
  -> 判定是否需要转换
       -> 不需要：创建会话，initStatus=SUCCESS
       -> 需要且未转换：提交异步任务，initStatus=CONVERTING
       -> 不支持预览：initStatus=NOT_SUPPORTED
       -> 仅下载分享：initStatus=DOWNLOAD_ONLY
  -> 返回 previewId + 文件信息 + 能力清单 + 转换状态
后续请求
  -> 凭 previewId 取状态 / 内容 / 下载
  -> 每次请求重新校验会话、权限、分享状态、配置闸门
```

### 3.2 访问模型

| 入口 | 身份 | 判定条件 | 会话主体 |
| --- | --- | --- | --- |
| A 登录访问 | 登录用户 | 上传人/管理员/业务授权；或文件 `access_scope=public` | `USER + userId` |
| B 匿名公开 | 未登录 | 文件 `access_scope=public` 且用途 `public_allowed=1` | `ANON + 匿名会话 Cookie` |
| C1 链接分享 | 未登录/外部 | `shareToken` 有效，`requireCode=true` 时提取码校验通过 | `SHARE_LINK + shareId` |
| C2 指定用户分享 | 登录用户 | 登录态有效 + `sys_file_share_receiver` 存在 + 分享有效，`requireCode=true` 时提取码校验通过 | `SHARE_USER + shareId + receiverId` |

规则：

1. 带 `shareTicket` 时一律按分享权限执行，不叠加登录身份。
2. `USER` 分享必须登录，先校验接收人再校验提取码，非接收人直接 403，不暴露“该分享是否存在提取码”。
3. 匿名会话下发 `xht_pv_anon` Cookie（HttpOnly、Secure、SameSite=Lax），TTL 10 分钟滑动、绝对上限 30 分钟。
4. `shareTicket` TTL 2 小时滑动，不超过分享剩余有效期。
5. 分享会话一律 `capabilities.share=false`。
6. IP + UA 仅用于风控与审计，不作为唯一绑定，避免移动网络切换误伤。

### 3.3 配置模型（四层）

| 层 | 存储 | 维护人 | 负责内容 |
| --- | --- | --- | --- |
| 全局 | `sys_file_setting` | 管理员 | 平台策略：分享上限、转换保留、会话 TTL、owner-override、匿名下载 |
| 用途 | `sys_file_used` | 管理员 | 业务策略：访问范围、公开能力、下载/打印/分享、图片模式、分享期限 |
| 后缀 | `sys_file_type` | 管理员 | 技术策略：预览类型、转换目标 |
| 文件 | `sys_file.file_config` | 上传人（受策略约束） | 单文件覆盖，默认只能收紧 |

优先级：

- 技术键：文件级（若允许）> 后缀配置 > 全局 > 代码默认。
- 业务键：文件级（若允许）> 用途配置 > 全局 > 代码默认。
- 平台键：全局，不允许文件级覆盖。

### 3.4 关键设计决策

| # | 决策 |
| --- | --- |
| 1 | 初始化/预览/下载支持未登录访问公开文件 |
| 2 | `access_scope`：private/public，公开仅管理员可控 |
| 3 | 下载 = 权限授予 且 配置闸门 |
| 4 | `owner-override=true`，上传人/管理员绕过下载/打印闸门 |
| 5 | 分享默认 7 天、上限 30 天 |
| 6 | 分享三态：`VIEW` / `VIEW_DOWNLOAD` / `DOWNLOAD` |
| 7 | 提取码 4~8 位字母数字，可自定义或随机 6 位 |
| 8 | 转换异步轮询；`DOWNLOAD` 分享不触发转换 |
| 9 | 转换产物默认 7 天，分享可延长，定时清理；源文件删除不立即清理 |
| 10 | 图片不统一转 PDF，按用途配置 `original/webp/pdf` |
| 11 | 用途配置化，内置 6 个种子，支持自定义 |
| 12 | 自定义用途可由管理员开启 `public_allowed` |
| 13 | 管理端可配全局/用途/后缀策略，并指定用户可覆盖项与方向 |
| 14 | 用户上传先读生效配置，再做文件级覆盖，只能收紧 |
| 15 | 旧 `GET /preview?fileStorageKey=`、`GET /download/{fileStorageKey}` 立即下线 |
| 16 | 分享分两种模式：链接分享 `LINK`、指定用户分享 `USER` |
| 17 | 两种模式的提取码都可选，由 `requireCode` 独立控制 |
| 18 | 新增分享中心：“我分享的 / 分享给我的” |
| 19 | 指定用户分享的接收人按创建时快照落库，部门/角色不动态跟随 |

## 4. 权限与能力

### 4.1 两个权限位

| 权限 | 含义 | 来源 |
| --- | --- | --- |
| `VIEW` | 能否初始化、能否获取预览内容 | 归属、业务授权、公开范围、分享权限 |
| `DOWNLOAD` | 能否下载原始文件 | 归属、业务授权、公开范围授予、分享权限 |

`VIEW` 与 `DOWNLOAD` 相互独立。`DOWNLOAD` 分享允许“无预览、仅下载”。

### 4.2 权限来源

| 主体 | VIEW | DOWNLOAD |
| --- | --- | --- |
| 上传人 / 管理员 | 是 | 是 |
| 业务授权人 | `FilePermissionProvider` 返回 | `FilePermissionProvider` 返回 |
| 公开文件 · 登录用户 | 是 | 由 `download.public-logged-in` 授予 |
| 公开文件 · 匿名 | 是 | 由 `download.anonymous-public` 授予（默认否） |
| 链接分享 · `SHARE_LINK` | 按分享权限 | 按分享权限 |
| 指定用户分享 · `SHARE_USER` | 接收人存在且分享有效，按分享权限 | 接收人存在且分享有效，按分享权限 |

`FilePermissionProvider` 返回决策对象，而非布尔：

```java
FileAccessDecision {
    boolean canView;
    boolean canDownload;
}
```

### 4.3 配置闸门

| 层级 | 配置 | 说明 |
| --- | --- | --- |
| 文件级 | `file_config.downloadAllowed` | 用户覆盖，仅可收紧 |
| 用途级 | `sys_file_used.download_allowed` | 业务策略 |
| 全局 | `download.default-allow` | 兜底 |

`owner-override=true` 时，上传人/管理员可绕过下载/打印闸门，但不改变权限位；分享访问不享受 owner-override。

### 4.4 判定公式

```
canView     = hasViewPermission     && shareAllowsView
canDownload = hasDownloadPermission && downloadGate && shareAllowsDownload
canPrint    = canView && canDownload && printGate
canShare    = isOwnerOrAdmin && shareEnabled && shareGate
```

其中：

- `shareAllowsView`：分享权限为 `VIEW` 或 `VIEW_DOWNLOAD`。
- `shareAllowsDownload`：分享权限为 `VIEW_DOWNLOAD` 或 `DOWNLOAD`。
- `SHARE_USER` 的 `hasViewPermission` / `hasDownloadPermission` 以接收人记录存在为前提。
- `downloadGate`：文件级 > 用途级 > 全局。
- `printGate`：文件级 > 用途级 > 全局。
- `shareGate`：文件级 > 用途级 > 全局。

### 4.5 能力矩阵

| 场景 | preview | download | print | share |
| --- | --- | --- | --- | --- |
| 登录 · 上传人/管理员 | 是 | 是（owner-override） | 按配置 | 是 |
| 登录 · 合同授权人（有下载授予） | 是 | 否（用途禁下） | 否 | 否 |
| 登录 · 合同授权人（仅查看授予） | 是 | 否 | 否 | 否 |
| 登录 · 通知/文档 | 是 | 是 | 是 | 是/按配置 |
| 匿名 · 公开通知 | 是 | 配置授予才可下 | 否 | 否 |
| 分享 · `VIEW` | 是 | 否 | 否 | 否 |
| 分享 · `VIEW_DOWNLOAD` | 是 | 是 | 是 | 否 |
| 分享 · `DOWNLOAD` | 否 | 是 | 否 | 否 |

说明：上表按分享权限列出；`LINK` 模式额外校验 `shareToken` 与可选提取码，`USER` 模式额外校验登录态与接收人记录，二者不改变权限矩阵本身。

### 4.6 权限过滤器改造

1. `DefaultFilePermissionFilter#doFilter` 必须实现：管理员、上传人放行；其他用户按业务授权判定。
2. `FilePermissionFilter` 增加动作维度：`PREVIEW`、`DOWNLOAD`、`SHARE`。
3. 新增 `XhtFilePermissionContext#decide(file, subject)` 返回 `FileAccessDecision`；原 `check` 保留为“查看权限不通过即抛异常”的语法糖。
4. 每次内容、下载、分享请求都重新执行判定，不复用初始化时的结果。
5. 未登录访问私有文件返回 401；已登录但无权限返回 403，且不返回文件元信息。

### 4.7 公开文件与匿名访问

- `sys_file.access_scope`：`private`（默认）/ `public`。
- 公开来源只有两种：用途默认 `access_scope=public`，或管理员对单文件设置。
- 上传人不能自行把文件设为公开。
- 管理员把文件设为 public 前，必须校验该文件用途 `public_allowed=1`，否则 400。
- 公开转私有后，匿名会话下次请求即失效。

## 5. 配置体系

### 5.1 用途配置 `sys_file_used`

用途由枚举改为配置表，内置 6 个种子，`built_in=1` 的不可删除、不可改 code。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | bigint | 主键 |
| `used_code` | varchar(32) | 用途编码，创建后不可改 |
| `used_name` | varchar(64) | 用途名称 |
| `description` | varchar(500) | 描述 |
| `built_in` | tinyint | 1=内置 |
| `enabled` | tinyint | 1=启用 |
| `sort` | int | 排序 |
| `access_scope` | varchar(20) | 默认访问范围 private/public |
| `public_allowed` | tinyint | 是否允许设为 public |
| `download_allowed` | tinyint | 下载闸门 |
| `print_allowed` | tinyint | 打印闸门 |
| `share_allowed` | tinyint | 分享闸门 |
| `share_expire_days` | int | 默认分享天数，空则继承全局 |
| `share_max_access_count` | int | 分享访问次数上限，空则继承全局；0=不限 |
| `image_mode` | varchar(20) | original/webp/pdf，空则继承全局 |
| `config_version` | int | 配置版本，用于缓存与审计 |
| `create_by/create_time/update_by/update_time` | - | 审计字段 |

内置种子：

| code | 名称 | 范围 | 公开能力 | 下载 | 打印 | 分享 | 图片模式 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `temp` | 临时文件 | private | 否 | 是 | 是 | 否 | 继承 |
| `avatar` | 头像 | public | 是 | 是 | 否 | 否 | original |
| `notice` | 通知附件 | public | 是 | 是 | 是 | 否 | original |
| `contract` | 合同附件 | private | 否 | 否 | 否 | 是 | pdf |
| `document` | 文档资料 | private | 否 | 是 | 是 | 是 | 继承 |
| `other` | 其他 | private | 否 | 是 | 是 | 是 | 继承 |

规则：

1. `used_code` 格式 `^[a-z][a-z0-9_]{1,31}$`，唯一，创建后不可修改。
2. 内置用途不可删除；自定义用途仅引用文件数为 0 时允许物理删除。
3. 停用用途后，新上传拒绝；存量文件继续按原策略访问。
4. 关闭 `public_allowed` 时，该用途下 `access_scope=public` 的文件强制转 private，匿名会话下次请求失效。
5. 开启 `public_allowed` 不追溯存量文件。
6. 关闭公开能力、批量转私有属于高风险操作，需独立权限 `file:used:publish`、二次确认与审计。

### 5.2 后缀配置 `sys_file_type`

在现有表上扩展技术字段，不承载业务策略：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `convert_target` | varchar(20) | `pdf` / 空；非空即表示需要转换 |
| `sort` | int | 排序 |

规则：

1. `file_suffix` 为空的行作为默认行，兜底未配置后缀。
2. `preview_type=other` 表示不支持内联预览。
3. 保存后清 `file:preview:type:{suffix}` 缓存。
4. `convert_target` 变更后，该后缀已有转换记录置为过期，下次预览重转。
5. `SysFileTypeDaoImpl#findConfigBySuffix` 必须查询 `convert_target`。

### 5.4 文件级覆盖 `sys_file.file_config`

只存用户改过的 key，未覆盖项继续继承。示例：

```json
  "shareExpireDays": 3
}
```

允许覆盖的 key：

| Key | 默认方向 | 说明 |
| --- | --- | --- |
| `downloadAllowed` | TIGHTEN_ONLY | 可关不可开 |
| `printAllowed` | TIGHTEN_ONLY | 可关不可开 |

| 类型 | TIGHTEN_ONLY |
| --- | --- |
| 布尔 | true→false 允许，false→true 拒绝 |

| 枚举（图片模式） | 仅 FREE，否则 LOCKED |

### 5.5 生效与缓存

1. 启动加载全部配置到本地缓存（Caffeine）+ Redis Hash `file:setting:all`。
2. 保存后更新 DB、递增 `version`、写 `sys_file_config_log`，发 Redis 频道 `file:setting:refresh` 通知各实例刷新。
3. 业务代码统一通过 `FilePolicyResolver` 读取，禁止直接查表。
4. 配置变更连带清理：
   - 用途/后缀变更：清对应缓存；
   - 图片模式/转换目标变更：该用途/后缀转换记录置过期；
   - 下载/打印变更：无需清缓存，下次请求实时判定。
5. Redis 不可用时降级读本地缓存；本地缓存过期后读 DB，不允许因配置中心故障导致预览不可用。

## 6. 预览会话

### 6.1 `previewId`

- 格式：`pv_` + 32 位 UUID（去横线）。
- 不可枚举，不包含 `fileId`、`storageKey`、`userId` 等可推断信息。
- 会话记录：`previewId`、`subjectType`、`subjectId`、`fileId`、`previewMode`、`previewSource`、`convertTaskId`、`shareId`、`receiverId`、`createdAt`。
- 所有后续接口只接受 `previewId`，不再接受 `fileStorageKey`。

### 6.2 存储与 TTL

| 主体 | 存储 | TTL |
| --- | --- | --- |
| 登录用户 | Redis Hash `file:preview:session:{previewId}` | 30 分钟滑动，绝对上限 2 小时 |
| 匿名公开 | 同上，`subjectType=ANON` | 10 分钟滑动，绝对上限 30 分钟 |
| 链接分享 | 同上，`subjectType=SHARE_LINK` | 30 分钟滑动，不超过分享剩余有效期 |
| 指定用户分享 | 同上，`subjectType=SHARE_USER`，记录 `receiverId` | 30 分钟滑动，不超过分享剩余有效期 |

### 6.3 幂等与并发

- 同一主体 + 同一文件 + 同一访问方式，5 分钟内重复初始化返回同一 `previewId`。
- 幂等索引：`file:preview:user:{subjectType}:{subjectId}:{fileId}:{shareId}:{receiverId}` → `previewId`。
- 初始化使用分布式锁 `file:preview:init:{fileId}`，防止并发重复创建转换任务。

### 6.4 失效

- 会话过期：410 + `PREVIEW_SESSION_EXPIRED`。
- 权限被收回：下次请求 403。
- 分享撤销/过期：下次请求 410 + `SHARE_NOT_EXIST_OR_EXPIRED`。
- 指定用户分享的接收人记录被删除：下次请求 403 + `SHARE_RECEIVER_NOT_FOUND`。
- 文件删除：404 + `FILE_NOT_EXIST`。
- 公开转私有：匿名会话下次请求 403。

## 7. 文件类型与转换

### 7.1 预览类型映射

| 后缀 | 预览模式 | 处理 |
| --- | --- | --- |
| jpg/jpeg/png/gif/webp/avif | image | 原图直出 |
| svg | image | 原文件 + `CSP: sandbox`，或转 PNG；不转 PDF |
| bmp/tif/tiff/heic/heif | image | 按用途 `image_mode`；默认转 WebP |
| pdf | pdf | 原文件直出，支持 Range |
| doc/docx/rtf/odt | pdf | LibreOffice 转 PDF |
| xls/xlsx/ods | pdf | LibreOffice 转 PDF |
| ppt/pptx/odp | pdf | LibreOffice 转 PDF |
| txt/md/log/csv | text | 分页 JSON |
| json/xml/yaml | json | 原文件直出 |
| mp4/webm/mov | video | Range 直出 |
| mp3/wav/aac/flac/m4a | audio | Range 直出 |
| zip/rar/7z/exe/apk 等 | other | 不支持预览，仅下载 |

### 7.2 图片策略

图片不做全局统一 PDF 转换，按用途配置：

| `image_mode` | 行为 | `previewMode` |
| --- | --- | --- |
| `original` | 原图直出；不兼容格式转 WebP | image |
| `webp` | 统一转 WebP（质量 85，最长边 ≤4096） | image |
| `pdf` | 单图转 PDF（96 DPI，保持方向与比例） | pdf |

边界：

- 动图 GIF 保持原文件，不转 WebP/PDF。
- SVG 不转 PDF。
- 多图合并 PDF 属于业务归档能力，不在本接口范围。
- `contract` 默认 `pdf`，`document/notice/avatar` 默认继承或 `original`。
- 转换后 `previewSource=CONVERT`；下载仍返回原始文件。

### 7.3 转换任务

- 任务表：`sys_file_convert`。
- 去重键：`file_id + target_format`。同一文件同一目标格式只保留一条任务；不同文件即使 hash 相同也各自转换，避免产物生命周期耦合。
- 状态：`0 PENDING`、`1 PROCESSING`、`2 SUCCESS`、`3 FAILED`。
- 任务提交后由异步线程池执行，初始化立即返回 `CONVERTING`。
- 进度只承诺粗粒度（0/50/100），不承诺精确百分比。

### 7.4 异步与线程池

- 转换线程池 `file-convert-executor`，不与 `xht-async-executor` 共用。
- 核心/最大线程数建议 `max(2, CPU/2)`，有界队列，队列满返回 `FILE_CONVERT_BUSY`。
- 单任务超时 `convert.timeout-seconds`，超时标记 FAILED。
- 重试 `convert.max-retry`，指数退避。
- 转换器抽象 `FileConverter`：`supports(sourceSuffix, targetFormat)` + `convert(...)`。
- 首批实现：`LibreOfficeConverter`、`ImageToWebpConverter`、`ImageToPdfConverter`。

### 7.5 失败与降级

- 转换失败：`initStatus=FAILED`，`preview=false`、`download=true`，返回可读 message。
- 转换器不可用/队列满：不返回 500，降级为仅下载。
- 内容接口在转换中返回 409 + `Retry-After`，客户端先轮询状态。
- 手动重试：再次初始化时若任务 FAILED 且未超过重试上限，重置为 PENDING。

### 7.6 产物生命周期

```
expire_time = max(转换完成时间 + convert.retention-days,
                  最新有效分享的 expire_time + convert.share-buffer-days)
```

- 默认保留 7 天；分享可延长；最长 `convert.max-retention-days`（默认 31 天）。
- 只延长不缩短。
- 分享创建时触发延长；分享撤销不缩短。
- 产物过期后再次预览：复用原任务行，重置为 PENDING 重新转换。
- 源文件删除：不立即清理产物；分享置为失效，产物到期后由定时任务清理。
- 清理任务每日 03:00 执行，分布式锁防重复；扫描 `status=SUCCESS AND expire_time < now`，二次检查是否存在有效分享，再删除存储对象与任务记录。
- 孤儿产物（存储中存在、无任务记录引用）超过 24 小时删除。

### 7.7 转换安全

- LibreOffice headless，独立 `UserInstallation` 目录，禁用宏、禁用恢复、只读源文件。
- 临时目录隔离，任务结束清理。
- 禁止拼接 shell 命令，参数使用数组传递。
- 源文件大小、页数、超时均有限制。
- 转换产物不注册为新的 `sys_file` 记录，避免污染用户文件列表。

## 8. 分享

### 8.1 分享模式

| 模式 | `share_mode` | 目标 | 访问方式 | 提取码 | 出现在“分享给我的” |
| --- | --- | --- | --- | --- | --- |
| 链接分享 | `LINK` | 任何人/外部 | `shareToken` | 由 `requireCode` 控制，可选 | 否 |
| 指定用户分享 | `USER` | 站内用户/部门/角色 | 登录 + 接收人校验 | 由 `requireCode` 控制，可选 | 是 |

规则：

1. `LINK` 允许匿名访问，`shareToken` 是访问定位凭证，不包含 `fileStorageKey`。
2. `USER` 必须登录；服务端校验 `sys_file_share_receiver` 接收人记录，不接受仅凭 `shareToken` 访问。
3. `USER` 模式仍生成 `shareToken` 用于内部定位与审计，但不对外暴露为访问链接。
4. 接收人按创建时**快照展开**落库：选部门/角色时展开为具体用户，后续人员变动不影响已创建分享；新成员看不到历史分享。
5. 同一用户被多个部门/角色选中时按 `(share_id, receiver_id)` 去重。
6. 禁止分享给自己；单次接收人上限由 `share.receiver.max-count` 控制（默认 500）。

### 8.2 三态权限

| 分享权限 | preview | download | print | 触发转换 | `initStatus` |
| --- | --- | --- | --- | --- | --- |
| `VIEW` | 是 | 否 | 否 | 需要则触发 | 0/1/2/3 |
| `VIEW_DOWNLOAD` | 是 | 是 | 是 | 需要则触发 | 0/1/2/3 |
| `DOWNLOAD` | 否 | 是 | 否 | 不触发 | 4 `DOWNLOAD_ONLY` |

规则：

1. `DOWNLOAD` 分享只发下载凭证，不生成预览内容、不创建转换任务。
2. `DOWNLOAD` 分享初始化返回 `previewMode=other`、`preview=false`、`download=true`。
3. 创建 `VIEW`/`VIEW_DOWNLOAD` 时，`preview_type=other` 的文件拒绝，提示选择仅下载分享。
4. 创建 `VIEW_DOWNLOAD`/`DOWNLOAD` 时，必须同时满足下载授予与配置闸门，否则 400。
5. 运行时每次下载重新校验分享状态、有效期、权限、配置闸门。

### 8.3 提取码（可选）

| 项 | 规则 |
| --- | --- |
| 是否必填 | 由 `requireCode` 控制，`LINK` / `USER` 均适用 |
| 长度 | 4~8 位 |
| 字符集 | `[A-Za-z0-9]` |
| 大小写 | 不敏感，统一转大写后 BCrypt 存储 |
| 随机生成 | `requireCode=true` 且未传 `accessCode` 时，默认 6 位，排除易混淆字符 `0 O 1 I L` |
| 自定义校验 | 4~5 位必须同时含字母和数字；6~8 位不限制组合 |
| 弱码拦截 | 拒绝 `123456`、`111111`、`abc123`、`password`、`qwerty`、全同字符等 |
| 存储 | BCrypt（strength 10），不存明文、不写日志；`requireCode=false` 时哈希为空 |
| 返回 | 仅 `requireCode=true` 的创建响应返回一次明文 `accessCode` |
| 默认值 | `LINK` 默认 `true`，`USER` 默认 `false`，由全局配置控制 |
| 重置 | `POST /sys/files/share/{shareId}/reset-code`，仅 `requireCode=true` 可用；重置后旧 ticket 失效 |
| 无码链接 | 任何人拿到链接即可访问，建议 `permission=VIEW` 且有效期不超过 `share.link.no-code-max-expire-days` |

### 8.4 分享流程

#### 8.4.1 创建

1. `POST /sys/files/preview/share`：校验 `previewId`、`capabilities.share`、用途 `share_allowed`、有效期上限。
2. `LINK`：生成 `shareToken`；`requireCode` 决定是否生成提取码。
3. `USER`：展开接收人、去重、批量写 `sys_file_share_receiver`，写入 `receiver_count`。
4. 可选：按 `share.notice.enabled` 异步发送站内信，失败只记日志，不回滚分享。
5. 返回 `shareId`、`shareToken`（仅 `LINK` 外露）、`shareUrl`（仅 `LINK`）、一次性 `accessCode`（如有）、`permission`、`expireAt`、`receiverCount`。

#### 8.4.2 链接分享打开

1. `GET /sys/files/share/link/{token}/meta`：返回 `requireCode`、`permission`、`expireAt`、`status`、文件基础信息。
2. `POST /sys/files/share/link/{token}/open`：`requireCode=true` 时必须传 `accessCode`；通过后签发 `shareTicket`，访问次数 +1。
3. `POST /sys/files/preview/init`：携带 `shareTicket`，返回 `previewId`。

#### 8.4.3 指定用户打开

1. `GET /sys/files/share/received/page`：接收人列表。
2. `POST /sys/files/share/user/{shareId}/open`：必须登录；先校验接收人记录，再按 `requireCode` 校验提取码；通过后签发 `shareTicket`，置已读、记录 `first_view_time`。
3. `POST /sys/files/preview/init`：携带 `shareTicket`，返回 `previewId`。

#### 8.4.4 四种组合

| 分享模式 | `requireCode` | 打开顺序 |
| --- | --- | --- |
| `LINK` | `false` | `token` 有效 → 直接发 `shareTicket`（匿名） |
| `LINK` | `true` | `token` 有效 → 校验提取码 → 发 `shareTicket` |
| `USER` | `false` | 登录 → 校验接收人 → 发 `shareTicket` |
| `USER` | `true` | 登录 → 校验接收人 → 校验提取码 → 发 `shareTicket` |

| 分享人 | 姓名/账号 |
| 权限 | 仅查看 / 查看+下载 / 仅下载 |
| 状态 | 未读 / 已读 / 已过期 / 已失效 |
| 有效期 | 到期时间 |
| 首次查看 | |
| 操作 | 打开、下载（有权限时）、移除 |

规则：

1. 只查 `share_mode=USER`、当前用户存在接收人记录、`hidden=0`。
2. 默认未读优先、创建时间倒序。
3. 未读角标：`GET /sys/files/share/received/unread-count`。
4. 打开时自动置为已读并记录 `first_view_time`。
5. 已过期/已撤销记录保留可见（灰色），不可打开；可“移除”隐藏。
6. `VIEW` 分享不显示下载按钮；`DOWNLOAD` 分享不显示预览按钮。
7. `hidden=1` 只影响列表展示，不影响直接访问，直到分享过期/撤销。

#### 8.5.3 接收人与通知

- 接收人记录：`share_id`、`receiver_id`、`receiver_name`、`receiver_source`、`source_id`、`read_status`、`read_time`、`first_view_time`、`download_count`、`hidden`。
- 站内信：分享创建后异步发送，包含文件名、分享人、有效期、站内跳转地址；发送失败只记日志。
- 接收人账号停用后无法登录，记录保留。
- 管理员可查看全部分享记录用于审计，但默认不进入“分享给我的”。

### 8.6 有效期与撤销

- 默认 7 天，最大 30 天，由全局配置与用途配置共同约束。
- 无码链接分享有效期不超过 `share.link.no-code-max-expire-days`（默认 7 天）。
- 过期后 meta、open、content、download 全部返回 410。
- 撤销立即生效；不缩短转换产物期限。
- 源文件删除时分享置为 `status=2`（已失效）。

### 8.7 风控

- 同一 `token + IP` 10 分钟错 5 次锁 10 分钟；同一 token 1 小时错 20 次锁 1 小时。
- `USER` 模式按 `shareId + userId` 记录提取码失败次数，避免换 IP 绕过。
- 打开接口 5 次/分钟/IP。
- 分享访问记录 IP、UA、referer、shareId、receiverId、结果。
- 分享链接不包含 `fileStorageKey`。

## 9. 打印与防截屏

### 9.1 打印限制

- 前端：隐藏打印按钮、`@media print` 隐藏预览区、pdf.js 禁用打印。
- 后端：合同/文档类 PDF 可设置权限位 `canPrint=false`、`canModify=false`。
- 仅合规阅读器遵守，属于“降低便利性”，不是强制阻断。

### 9.2 防截屏边界

- 浏览器无法阻止操作系统截屏，也无法可靠检测截屏。
- 前端只能做威慑：失焦/切后台模糊、禁右键、禁复制。
- 强管控需要 DRM（Widevine/FairPlay）、原生客户端安全渲染或云桌面/VDI，不在本期范围。
- 需求验收口径为“降低复制便利性”，不承诺“防截屏”。

### 10.2 状态查询

`GET /sys/files/preview/status?previewId=`

返回 `initStatus`、`conversion`、`capabilities`、`expireAt`。会话不存在/过期返回 410。

### 10.3 内容

`GET /sys/files/preview/content?previewId=&offset=&pageNo=&size=&charset=`

- 支持 HTTP Range；命中单区间 206 + `Content-Range`，越界 416。
- 文本按字节块分页返回 JSON，参数与现有 `TextPreview` 保持一致。
- 转换中返回 409 + `Retry-After`。
- `preview=false` 的分享返回 403。
- `NOT_SUPPORTED` 返回 415 + `FILE_PREVIEW_NOT_SUPPORT`。

### 10.4 下载

`GET /sys/files/preview/download?previewId=`

- 始终下载原始文件，文件名取原始名。
- `capabilities.download=false` 返回 403。
- 每次请求重新校验权限、配置闸门、分享状态。

### 10.6 分享

#### 10.6.1 创建分享

`POST /sys/files/preview/share`

```json
{
  "previewId": "pv_xxx",
  "shareMode": "LINK",
  "permission": "VIEW_DOWNLOAD",
  "expireDays": 7,
  "requireCode": true,
  "accessCode": "A1B2C3",
  "maxAccessCount": 100,
  "receiverType": "USER",
  "receiverIds": [],
  "needNotice": false
}
```

规则：

- `shareMode=LINK`：`receiverType`/`receiverIds` 忽略；`shareToken`、`shareUrl` 返回给创建者。
- `shareMode=USER`：`receiverIds` 必填，单次不超过 `share.receiver.max-count`；不返回可对外传播的分享链接。
- `requireCode=true` 且 `accessCode` 为空：服务端随机生成 6 位；`requireCode=false`：忽略 `accessCode`。
- `maxAccessCount` 仅对 `LINK` 生效；`USER` 模式忽略。
- 禁止分享给自己。

响应返回：`shareId`、`shareMode`、`shareToken`（仅 `LINK`）、`shareUrl`（仅 `LINK`）、`accessCode`（仅 `requireCode=true`，仅一次）、`permission`、`expireAt`、`receiverCount`。

#### 10.6.2 链接分享访问

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/sys/files/share/link/{token}/meta` | GET | 返回 `requireCode`、`permission`、`expireAt`、`status`、文件基础信息 |
| `/sys/files/share/link/{token}/open` | POST | 有码必填 `accessCode`，无码直接打开；返回 `shareTicket` |

#### 10.6.3 指定用户分享访问

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/sys/files/share/user/{shareId}/meta` | GET | 必须登录且是接收人 |
| `/sys/files/share/user/{shareId}/open` | POST | 登录 + 接收人校验；有码时校验提取码；返回 `shareTicket` |

#### 10.6.4 分享中心

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/sys/files/share/page` | POST | 我创建的分享分页，支持文件名/模式/状态/权限筛选 |
| `/sys/files/share/{shareId}` | GET | 分享详情 |
| `/sys/files/share/{shareId}/receivers` | POST | 接收人分页（已读/未读、首次查看、下载次数） |
| `/sys/files/share/received/page` | POST | 分享给我的分页 |
| `/sys/files/share/received/unread-count` | GET | 未读数量 |
| `/sys/files/share/received/{receiverId}/read` | POST | 手动标记已读 |
| `/sys/files/share/received/{receiverId}/hide` | POST | 从我的列表移除 |
| `/sys/files/share/{shareId}` | DELETE | 撤销分享 |
| `/sys/files/share/{shareId}/reset-code` | POST | 重置提取码（仅 `requireCode=true`） |

`/verify` 不再单独保留，合并进 `/open`。

### 10.7 旧接口下线

| 接口 | 处理 |
| --- | --- |
| `GET /sys/files/preview?fileStorageKey=` | 立即删除路由，返回 404 |
| `GET /sys/files/download/{fileStorageKey}` | 立即删除路由，返回 404 |
| `GET /sys/files/preview/init` | 不再保留 GET 版本，统一 POST |
| `GET /sys/files/preview/init` 的旧响应字段 | 只增不改；`initStatus` 数值保留 0/1/2，新增 3/4 |

## 13. 非功能需求

| 维度 | 要求 |
| --- | --- |
| 性能 | 初始化 P95 ≤ 200ms（不含转换）；状态查询 P95 ≤ 50ms |
| 并发 | 转换线程池有界队列，队列满降级不阻塞主流程 |
| 可用性 | 转换不可用时降级为仅下载，不返回 500 |
| 安全 | `previewId` ≥128bit 熵、绑定主体、短期有效；日志不打印文件内容与提取码 |
| 限流 | 初始化 60 次/分钟/用户；匿名 30 次/分钟/IP；分享打开 5 次/分钟/IP |
| 分享中心 | 我分享的/分享给我的列表 P95 ≤ 300ms；接收人展开与通知异步化，不阻塞创建 |
| 缓存 | 配置本地缓存 + Redis；Redis 故障时读本地缓存，管理端保存失败但预览可用 |
| 可观测 | 指标：`preview_init_total{result}`、`convert_duration`、`convert_fail_total`、`share_open_total{result}`、`share_receiver_notice_total{result}` |
| 审计 | 初始化、下载、分享创建/打开/撤销、接收人变更、配置变更全部留痕 |
| 兼容 | 响应字段只增不改；枚举只加值；旧接口按第 10.7 节下线 |

## 14. 兼容与迁移

1. **P0 先修安全**：`/preview/init`、`/preview`、`/download` 收口登录 + 权限，否则文件模块等同公开。
2. 初始化改 `POST`，删除 GET 版本；前端同步改造。
3. 旧 `GET /preview?fileStorageKey=`、`GET /download/{fileStorageKey}` 立即删除路由。
4. `FileUsedEnum` 保留为内置常量与迁移种子，标记 `@Deprecated`；运行时校验改 `SysFileUsedService`。
5. 存量 `file_used` 值全部迁入 `sys_file_used`，未知值自动建为自定义用途。
6. `SysFileTypeDaoImpl#findConfigBySuffix` 增加 `convert_target` 查询字段。
7. `sys_file.file_config` 为增量字段，历史文件为 null，按继承处理。
8. `sys_file_share` 增加 `share_mode`、`require_code` 与接收人表；存量分享默认 `share_mode=LINK`、`require_code=1`。
9. 指定用户分享的接收人按创建时快照落库；部门/角色后续人员变动不回溯，需在页面明确提示。
10. 前端灰度：先双读（有 `previewId` 走新链路，无则回退），再切主流程，最后下旧接口。
