## 1. 文档说明

### 1.1 目的

把现有 `/sys/files/preview/init` 从“返回文件基础信息”升级为“创建一次预览会话”：一次调用完成登录识别、文件归属与业务授权、预览类型识别与会话创建，返回 `previewId`、文件信息、能力清单与初始化状态。后续预览、下载统一以 `previewId` 为凭证，不再直接暴露 `fileStorageKey`。

### 1.2 范围

本文覆盖：

- 预览初始化、状态查询、内容获取、下载；
- 公开文件与匿名访问；
- 文件用途、后缀、全局、文件级四层配置；
- 打印限制、防截屏边界；
- 管理端配置页面与接口；
- 旧接口下线与数据迁移。

不覆盖：在线编辑、OCR、缩略图、多图合并 PDF、DRM/原生客户端、病毒扫描。

### 1.3 术语

| 术语 | 说明 |
| --- | --- |
| 预览会话 | 由 `previewId` 标识的一次访问上下文，绑定访问主体、文件与预览模式 |
| `previewId` | 预览会话唯一标识，`pv_` + 32 位 UUID（去横线），不可枚举 |
| 能力 | `preview` / `download` / `print` 三个布尔值 |
| 访问主体 | `USER`（登录用户）、`ANON`（匿名公开访问） |
| 权限授予（grant） | 主体是否具备查看/下载资格 |
| 配置闸门（gate） | 该用途/该文件是否允许下载/打印 |

## 2. 背景与现状

### 2.1 现有能力

- 文件上传、分片上传、合并、下载、预览初始化、预览内容输出已收敛在 `SysFileController` 与 `ISysFileService`。
- 预览按 `sys_file_type` 的后缀映射分派到 `FilePreview` 实现：`text` 返回分页 JSON，`image/pdf/video/audio/json` 原样输出，`other` 返回下载提示。
- 权限校验框架为 `XhtFilePermissionContext` + `FilePermissionFilter` 链式过滤器。
- 文件用途为硬编码枚举 `FileUsedEnum`：`temp/avatar/notice/contract/document/other`。

### 2.2 现存问题

| # | 问题 | 代码依据 | 影响 |
| --- | --- | --- | --- |
| 1 | 预览初始化匿名可调 | `SysFileController.java:195` 标注 `@IgnoreAuth(aop = false)`，该注解会将 URL 加入 Security 白名单 | 未登录即可获取文件元信息 |
| 2 | 没有真正的归属校验 | `DefaultFilePermissionFilter.java:43-44` 的 `doFilter` 为空实现 | 拿到 `fileStorageKey` 即可越权预览/下载 |
| 3 | 初始化接口当前必失败 | `SysFileServiceImpl.java:167-170` 未设置 `initStatus`，`SysFilePreviewBuilder.java:97` 断言其非空 | 调用必抛“预览状态【initStatus】不能为空” |
| 4 | `previewId` 永远为 null | `SysFilePreviewBuilder.java:99-108` 从未赋值 | 无会话句柄，无法承载后续操作 |
| 5 | 无格式转换能力 | `ISysFileService.java:100` 明确“不做格式转换” | Word/Excel/PPT 只能下载 |
| 6 | 用途硬编码 | `FileUsedEnum.java:24-49` | 新增用途必须发版 |
| 7 | 文档与实现不一致 | `开发规范和编码指南.md:855` 写 `POST /preview/init` 且返回 `previewUrl/downloadUrl`，实际为 GET 且响应无 URL | 前端按文档对接会踩空 |

### 2.3 本次目标

1. 一次初始化完成鉴权、授权、类型识别、会话创建。
2. 支持两种访问入口：登录用户、匿名公开文件。
3. 权限与配置分离：权限决定“能不能看”，权限 + 配置决定“能不能下”。
4. 用途、后缀、全局、文件级四层配置，管理端可配，用户只能收紧。
5. 后缀 → 预览类型映射可配置，不支持的类型统一走“仅下载”。
6. 打印可限制，明确防截屏边界。
7. 下线旧预览/下载接口，收敛到 `previewId`。

### 2.4 非目标

在线编辑、OCR、缩略图、多图合并 PDF、DRM/原生客户端、病毒扫描、跨租户资源共享。

## 3. 总体设计

### 3.1 核心思路

```
初始化请求
  -> 识别访问主体（登录 / 匿名公开）
  -> 定位文件并校验查看权限
  -> 读取四层配置，计算预览模式、下载/打印能力
  -> 判定初始化状态
       -> 可预览：initStatus=SUCCESS
       -> 不支持预览：initStatus=NOT_SUPPORTED
       -> 仅下载：initStatus=DOWNLOAD_ONLY
  -> 返回 previewId + 文件信息 + 能力清单 + 初始化状态
后续请求
  -> 凭 previewId 取状态 / 内容 / 下载
  -> 每次请求重新校验会话、权限、配置闸门
```

### 3.2 访问模型

| 入口 | 身份 | 判定条件 | 会话主体 |
| --- | --- | --- | --- |
| A 登录访问 | 登录用户 | 上传人/管理员/业务授权；或文件 `access_scope=public` | `USER + userId` |
| B 匿名公开 | 未登录 | 文件 `access_scope=public` 且用途 `public_allowed=1` | `ANON + 匿名会话 Cookie` |

规则：

1. 匿名会话下发 `xht_pv_anon` Cookie（HttpOnly、Secure、SameSite=Lax），TTL 10 分钟滑动、绝对上限 30 分钟。
2. IP + UA 仅用于风控与审计，不作为唯一绑定，避免移动网络切换误伤。

### 3.3 配置模型（四层）

| 层 | 存储 | 维护人 | 负责内容 |
| --- | --- | --- | --- |
| 全局 | `sys_file_setting` | 管理员 | 平台策略：会话 TTL、owner-override、匿名下载 |
| 用途 | `sys_file_used` | 管理员 | 业务策略：访问范围、公开能力、下载/打印 |
| 后缀 | `sys_file_type` | 管理员 | 技术策略：后缀 → 预览类型映射 |
| 文件 | `sys_file.file_config` | 上传人（受策略约束） | 单文件覆盖，默认只能收紧 |

优先级：

- 技术键：文件级（若允许）> 后缀配置 > 全局 > 代码默认。
- 业务键：文件级（若允许）> 用途配置 > 全局 > 代码默认。
- 平台键：全局，不允许文件级覆盖。

### 3.4 关键设计决策

| # | 决策 |
| --- | --- |
| 1 | 初始化/预览/下载支持未登录访问公开文件 |
| 2 | `access_scope`：private/public，公开仅管理员可控 |
| 3 | 下载 = 权限授予 且 配置闸门 |
| 4 | `owner-override=true`，上传人/管理员绕过下载/打印闸门 |
| 5 | 不做文件格式转换，Office 等类型统一“仅下载” |
| 6 | 图片一律原图直出，不做 WebP/PDF 处理 |
| 7 | 用途配置化，内置 6 个种子，支持自定义 |
| 8 | 自定义用途可由管理员开启 `public_allowed` |
| 9 | 管理端可配全局/用途/后缀策略，并指定用户可覆盖项与方向 |
| 10 | 用户上传先读生效配置，再做文件级覆盖，只能收紧 |
| 11 | 旧 `GET /preview?fileStorageKey=`、`GET /download/{fileStorageKey}` 立即下线 |

## 4. 权限与能力

### 4.1 两个权限位

| 权限 | 含义 | 来源 |
| --- | --- | --- |
| `VIEW` | 能否初始化、能否获取预览内容 | 归属、业务授权、公开范围 |
| `DOWNLOAD` | 能否下载原始文件 | 归属、业务授权、公开范围授予 |

`VIEW` 与 `DOWNLOAD` 相互独立，允许“无预览、仅下载”。

### 4.2 权限来源

| 主体 | VIEW | DOWNLOAD |
| --- | --- | --- |
| 上传人 / 管理员 | 是 | 是 |
| 业务授权人 | `FilePermissionProvider` 返回 | `FilePermissionProvider` 返回 |
| 公开文件 · 登录用户 | 是 | 由 `download.public-logged-in` 授予 |
| 公开文件 · 匿名 | 是 | 由 `download.anonymous-public` 授予（默认否） |

`FilePermissionProvider` 返回决策对象，而非布尔：

```java
FileAccessDecision {
    boolean canView;
    boolean canDownload;
}
```

### 4.3 配置闸门

| 层级 | 配置 | 说明 |
| --- | --- | --- |
| 文件级 | `file_config.downloadAllowed` | 用户覆盖，仅可收紧 |
| 用途级 | `sys_file_used.download_allowed` | 业务策略 |
| 全局 | `download.default-allow` | 兜底 |

`owner-override=true` 时，上传人/管理员可绕过下载/打印闸门，但不改变权限位。

### 4.4 判定公式

```
canView     = hasViewPermission
canDownload = hasDownloadPermission && downloadGate
canPrint    = canView && canDownload && printGate
```

其中：

- `downloadGate`：文件级 > 用途级 > 全局。
- `printGate`：文件级 > 用途级 > 全局。

### 4.5 能力矩阵

| 场景 | preview | download | print |
| --- | --- | --- | --- |
| 登录 · 上传人/管理员 | 是 | 是（owner-override） | 按配置 |
| 登录 · 合同授权人（有下载授予） | 是 | 否（用途禁下） | 否 |
| 登录 · 合同授权人（仅查看授予） | 是 | 否 | 否 |
| 登录 · 通知/文档 | 是 | 是 | 是 |
| 匿名 · 公开通知 | 是 | 配置授予才可下 | 否 |

### 4.6 权限过滤器改造

1. `DefaultFilePermissionFilter#doFilter` 必须实现：管理员、上传人放行；其他用户按业务授权判定。
2. `FilePermissionFilter` 增加动作维度：`PREVIEW`、`DOWNLOAD`。
3. 新增 `XhtFilePermissionContext#decide(file, subject)` 返回 `FileAccessDecision`；原 `check` 保留为“查看权限不通过即抛异常”的语法糖。
4. 每次内容、下载请求都重新执行判定，不复用初始化时的结果。
5. 未登录访问私有文件返回 401；已登录但无权限返回 403，且不返回文件元信息。

### 4.7 公开文件与匿名访问

- `sys_file.access_scope`：`private`（默认）/ `public`。
- 公开来源只有两种：用途默认 `access_scope=public`，或管理员对单文件设置。
- 上传人不能自行把文件设为公开。
- 管理员把文件设为 public 前，必须校验该文件用途 `public_allowed=1`，否则 400。
- 公开转私有后，匿名会话下次请求即失效。

## 5. 配置体系

### 5.1 用途配置 `sys_file_used`

用途由枚举改为配置表，内置 6 个种子，`built_in=1` 的不可删除、不可改 code。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | bigint | 主键 |
| `used_code` | varchar(32) | 用途编码，创建后不可改 |
| `used_name` | varchar(64) | 用途名称 |
| `description` | varchar(500) | 描述 |
| `built_in` | tinyint | 1=内置 |
| `enabled` | tinyint | 1=启用 |
| `sort` | int | 排序 |
| `access_scope` | varchar(20) | 默认访问范围 private/public |
| `public_allowed` | tinyint | 是否允许设为 public |
| `download_allowed` | tinyint | 下载闸门 |
| `print_allowed` | tinyint | 打印闸门 |
| `config_version` | int | 配置版本，用于缓存与审计 |
| `create_by/create_time/update_by/update_time` | - | 审计字段 |

内置种子：

| code | 名称 | 范围 | 公开能力 | 下载 | 打印 |
| --- | --- | --- | --- | --- | --- |
| `temp` | 临时文件 | private | 否 | 是 | 是 |
| `avatar` | 头像 | public | 是 | 是 | 否 |
| `notice` | 通知附件 | public | 是 | 是 | 是 |
| `contract` | 合同附件 | private | 否 | 否 | 否 |
| `document` | 文档资料 | private | 否 | 是 | 是 |
| `other` | 其他 | private | 否 | 是 | 是 |

规则：

1. `used_code` 格式 `^[a-z][a-z0-9_]{1,31}$`，唯一，创建后不可修改。
2. 内置用途不可删除；自定义用途仅引用文件数为 0 时允许物理删除。
3. 停用用途后，新上传拒绝；存量文件继续按原策略访问。
4. 关闭 `public_allowed` 时，该用途下 `access_scope=public` 的文件强制转 private，匿名会话下次请求失效。
5. 开启 `public_allowed` 不追溯存量文件。
6. 关闭公开能力、批量转私有属于高风险操作，需独立权限 `file:used:publish`、二次确认与审计。

### 5.2 后缀配置 `sys_file_type`

在现有表上扩展技术字段，不承载业务策略：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `preview_type` | varchar(20) | 预览类型编码 |
| `file_suffix` | varchar(30) | 文件后缀，空行作为兜底 |
| `sort` | int | 排序 |

规则：

1. `file_suffix` 为空的行作为默认行，兜底未配置后缀。
2. `preview_type=other` 表示不支持内联预览。
3. 保存后清 `file:preview:type:{suffix}` 缓存。
4. 后缀改判 `other` 后，已有预览会话下次初始化即按“仅下载”处理。

### 5.3 全局配置 `sys_file_setting`

| Key | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| `file.default-used` | temp | 已启用用途 | 上传未传用途时的默认值 |
| `download.default-allow` | true | bool | 下载闸门兜底 |
| `download.owner-override` | true | bool | 上传人/管理员绕过闸门 |
| `download.anonymous-public` | false | bool | 匿名访问公开文件能否下载 |
| `download.public-logged-in` | true | bool | 登录用户访问公开文件能否下载 |
| `print.default-allow` | true | bool | 打印闸门兜底 |
| `preview.session.ttl-minutes` | 30 | 5~120 | 登录会话滑动 TTL |
| `preview.session.max-hours` | 2 | 1~24 | 会话绝对上限 |
| `preview.anonymous.ttl-minutes` | 10 | 5~60 | 匿名会话 TTL |

### 5.4 文件级覆盖 `sys_file.file_config`

只存用户改过的 key，未覆盖项继续继承。示例：

```json
{
  "downloadAllowed": false,
  "printAllowed": false
}
```

允许覆盖的 key：

| Key | 默认方向 | 说明 |
| --- | --- | --- |
| `downloadAllowed` | TIGHTEN_ONLY | 可关不可开 |
| `printAllowed` | TIGHTEN_ONLY | 可关不可开 |

不允许覆盖：`accessScope`、`previewType`、会话 TTL、匿名下载。

方向语义：

| 类型 | TIGHTEN_ONLY |
| --- | --- |
| 布尔 | true→false 允许，false→true 拒绝 |

### 5.5 生效与缓存

1. 启动加载全部配置到本地缓存（Caffeine）+ Redis Hash `file:setting:all`。
2. 保存后更新 DB、递增 `version`、写 `sys_file_config_log`，发 Redis 频道 `file:setting:refresh` 通知各实例刷新。
3. 业务代码统一通过 `FilePolicyResolver` 读取，禁止直接查表。
4. 配置变更连带清理：
   - 用途/后缀变更：清对应缓存；
   - 下载/打印变更：无需清缓存，下次请求实时判定。
5. Redis 不可用时降级读本地缓存；本地缓存过期后读 DB，不允许因配置中心故障导致预览不可用。

## 6. 预览会话

### 6.1 `previewId`

- 格式：`pv_` + 32 位 UUID（去横线）。
- 不可枚举，不包含 `fileId`、`storageKey`、`userId` 等可推断信息。
- 会话记录：`previewId`、`subjectType`、`subjectId`、`fileId`、`previewMode`、`createdAt`。
- 所有后续接口只接受 `previewId`，不再接受 `fileStorageKey`。

### 6.2 存储与 TTL

| 主体 | 存储 | TTL |
| --- | --- | --- |
| 登录用户 | Redis Hash `file:preview:session:{previewId}` | 30 分钟滑动，绝对上限 2 小时 |
| 匿名公开 | 同上，`subjectType=ANON` | 10 分钟滑动，绝对上限 30 分钟 |

### 6.3 幂等与并发

- 同一主体 + 同一文件 + 同一访问方式，5 分钟内重复初始化返回同一 `previewId`。
- 幂等索引：`file:preview:user:{subjectType}:{subjectId}:{fileId}` → `previewId`。
- 初始化使用分布式锁 `file:preview:init:{fileId}`，防止并发重复创建会话。

### 6.4 失效

- 会话过期：410 + `PREVIEW_SESSION_EXPIRED`。
- 权限被收回：下次请求 403。
- 文件删除：404 + `FILE_NOT_EXIST`。
- 公开转私有：匿名会话下次请求 403。

## 7. 文件类型与预览

### 7.1 预览类型映射

| 后缀 | 预览模式 | 处理 |
| --- | --- | --- |
| jpg/jpeg/png/gif/webp/svg | image | 原图直出 |
| bmp/tif/tiff/heic/heif | image | 原图直出；浏览器不支持时提示下载 |
| pdf | pdf | 原文件直出，支持 Range |
| doc/docx/rtf/odt | other | 不支持在线预览，仅下载 |
| xls/xlsx/ods | other | 不支持在线预览，仅下载 |
| ppt/pptx/odp | other | 不支持在线预览，仅下载 |
| txt/md/log/csv | text | 分页 JSON |
| json/xml/yaml | json | 原文件直出 |
| mp4/webm/mov | video | Range 直出 |
| mp3/wav/aac/flac/m4a | audio | Range 直出 |
| zip/rar/7z/exe/apk 等 | other | 不支持预览，仅下载 |

映射关系维护在 `sys_file_type`（后缀 → 预览类型）。不在表中的后缀走 `file_suffix` 为空的兜底行，默认 `other`。

### 7.2 图片处理

- 图片一律原图直出，不做格式转换、不转 PDF。
- 浏览器不兼容的格式（bmp/tif/tiff/heic/heif）仍按 `image` 预览，前端加载失败时降级为下载入口。
- 动图 GIF 保持原文件，不做处理。
- 多图合并、压缩、水印等属于业务归档能力，不在本接口范围。

## 8. 打印与防截屏

### 8.1 打印限制

- 前端：隐藏打印按钮、`@media print` 隐藏预览区、pdf.js 禁用打印。
- 后端：合同/文档类 PDF 可设置权限位 `canPrint=false`、`canModify=false`。
- 仅合规阅读器遵守，属于“降低便利性”，不是强制阻断。

### 8.2 防截屏边界

- 浏览器无法阻止操作系统截屏，也无法可靠检测截屏。
- 前端只能做威慑：失焦/切后台模糊、禁右键、禁复制。
- 强管控需要 DRM（Widevine/FairPlay）、原生客户端安全渲染或云桌面/VDI，不在本期范围。
- 需求验收口径为“降低复制便利性”，不承诺“防截屏”。

## 9. 接口设计

### 9.1 初始化

`POST /sys/files/preview/init`

请求：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `fileId` | Long | 二选一 | 推荐 |
| `fileStorageKey` | String | 二选一 | 兼容旧客户端 |

鉴权：登录或匿名公开访问。

响应：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `previewId` | String | 会话唯一 ID |
| `initStatus` | Integer | 0 SUCCESS / 2 NOT_SUPPORTED / 4 DOWNLOAD_ONLY |
| `previewMode` | String | image/pdf/video/audio/text/json/other |
| `fileName` | String | 展示名 |
| `fileOriginalName` | String | 原始名 |
| `fileSize` | Long | 字节 |
| `fileSizeInfo` | String | 人类可读 |
| `fileSuffix` | String | 后缀 |
| `fileType` | String | MIME |
| `accessScope` | String | private/public |
| `capabilities` | Object | `{preview, download, print}` |
| `urls` | Object | `{previewUrl, downloadUrl, statusUrl}` |
| `expireAt` | DateTime | 会话过期时间 |

示例：

```json
{
  "previewId": "pv_01JCBX8K3M9Q2V7T4R6S0A1B2C",
  "initStatus": 2,
  "previewMode": "other",
  "fileName": "2026年度经营分析.docx",
  "fileOriginalName": "2026年度经营分析.docx",
  "fileSize": 204800,
  "fileSizeInfo": "200 KB",
  "fileSuffix": "docx",
  "fileType": "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
  "accessScope": "private",
  "capabilities": { "preview": false, "download": true, "print": false },
  "urls": {
    "previewUrl": "/sys/files/preview/content?previewId=pv_01JCBX8K3M9Q2V7T4R6S0A1B2C",
    "downloadUrl": "/sys/files/preview/download?previewId=pv_01JCBX8K3M9Q2V7T4R6S0A1B2C",
    "statusUrl": "/sys/files/preview/status?previewId=pv_01JCBX8K3M9Q2V7T4R6S0A1B2C"
  },
  "expireAt": "2026-11-09T17:50:00+08:00"
}
```

### 9.2 状态查询

`GET /sys/files/preview/status?previewId=`

返回 `initStatus`、`previewMode`、`capabilities`、`expireAt`。会话不存在/过期返回 410。

### 9.3 内容

`GET /sys/files/preview/content?previewId=&offset=&pageNo=&size=&charset=`

- 支持 HTTP Range；命中单区间 206 + `Content-Range`，越界 416。
- 文本按字节块分页返回 JSON，参数与现有 `TextPreview` 保持一致。
- `capabilities.preview=false` 返回 403。
- `NOT_SUPPORTED` 返回 415 + `FILE_PREVIEW_NOT_SUPPORT`。

### 9.4 下载

`GET /sys/files/preview/download?previewId=`

- 始终下载原始文件，文件名取原始名。
- `capabilities.download=false` 返回 403。
- 每次请求重新校验权限与配置闸门。

### 9.5 上传配置

`GET /sys/files/config/upload?fileSuffix=docx&fileUsed=contract`

返回：

```json
{
  "fileSuffix": "docx",
  "fileUsed": "contract",
  "usedName": "合同附件",
  "items": [
    {
      "key": "downloadAllowed",
      "label": "允许下载",
      "effectiveValue": false,
      "source": "USED",
      "userEditable": false,
      "lockedReason": "合同类文件由管理员统一禁下"
    }
  ]
}
```

上传/合并接口新增 `fileConfig` 字段（JSON 对象字符串），只传用户修改项。

### 9.6 旧接口下线

| 接口 | 处理 |
| --- | --- |
| `GET /sys/files/preview?fileStorageKey=` | 立即删除路由，返回 404 |
| `GET /sys/files/download/{fileStorageKey}` | 立即删除路由，返回 404 |
| `GET /sys/files/preview/init` | 不再保留 GET 版本，统一 POST |
| `GET /sys/files/preview/init` 的旧响应字段 | 只增不改；`initStatus` 数值保留 0/1/2，新增 3/4 |

## 12. 非功能需求

| 维度 | 要求 |
| --- | --- |
| 性能 | 初始化 P95 ≤ 200ms；状态查询 P95 ≤ 50ms |
| 并发 | 初始化按 `fileId` 加分布式锁，避免同一文件重复建会话 |
| 可用性 | 存储或配置中心异常时降级为只读缓存，不返回 500 |
| 安全 | `previewId` ≥128bit 熵、绑定主体、短期有效；日志不打印文件内容 |
| 限流 | 初始化 60 次/分钟/用户；匿名 30 次/分钟/IP |
| 缓存 | 配置本地缓存 + Redis；Redis 故障时读本地缓存，管理端保存失败但预览可用 |
| 可观测 | 指标：`preview_init_total{result}`、`preview_download_total{result}` |
| 审计 | 初始化、下载、配置变更全部留痕 |
| 兼容 | 响应字段只增不改；枚举只加值；旧接口按第 9.6 节下线 |

## 13. 兼容与迁移

1. **P0 先修安全**：`/preview/init`、`/preview`、`/download` 收口登录 + 权限，否则文件模块等同公开。
2. 初始化改 `POST`，删除 GET 版本；前端同步改造。
3. 旧 `GET /preview?fileStorageKey=`、`GET /download/{fileStorageKey}` 立即删除路由。
4. `FileUsedEnum` 保留为内置常量与迁移种子，标记 `@Deprecated`；运行时校验改 `SysFileUsedService`。
5. 存量 `file_used` 值全部迁入 `sys_file_used`，未知值自动建为自定义用途。
6. `sys_file.file_config` 为增量字段，历史文件为 null，按继承处理。
7. 历史能力残留清理（分享 / 转换 / 水印）由 `doc/sql/file-preview-v2.sql` 第 8 节统一负责：删表、删列、删配置项，幂等可重复执行。
8. 前端灰度：先双读（有 `previewId` 走新链路，无则回退），再切主流程，最后下旧接口。

## 14. 验收标准

| # | 场景 | 预期 |
| --- | --- | --- |
| 1 | 未登录初始化私有文件 | 401，不返回文件信息 |
| 2 | 未登录初始化公开文件 | 200，可看；下载按配置 |
| 3 | 非上传人/非管理员初始化私有文件 | 403 |
| 4 | 上传人初始化 docx | `previewId` 非空、`initStatus=2`、`previewMode=other`、`preview=false` |
| 5 | 5 分钟内重复初始化同一文件 | 返回同一 `previewId`，不重复建会话 |
| 6 | PDF 文件初始化 | `initStatus=0`、`previewMode=pdf`、内容 `application/pdf`、支持 206 |
| 7 | docx 取内容 | 415 `FILE_PREVIEW_NOT_SUPPORT`，下载 200 |
| 8 | 用他人 `previewId` 取内容 | 403 |
| 9 | 会话过期后取内容 | 410 |
| 10 | 业务授权仅查看、配置允许下载 | `capabilities.download=false`，下载 403 |
| 11 | 合同授权人有下载授予、用途禁下 | 下载 403；上传人 owner-override 可下 |
| 12 | 图片（任意用途） | `previewMode=image`，原图直出 |
| 13 | 源文件删除 | 预览返回文件不存在 |
| 14 | 旧 `GET /preview?fileStorageKey=` | 404 |
| 15 | 旧 `GET /download/{fileStorageKey}` | 404 |
| 16 | 用途停用 | 新上传 400；存量文件仍可预览 |
| 17 | 删除有引用的用途 | 400，提示先停用 |
| 18 | 用户覆盖 `downloadAllowed` 为 true（用途禁下） | 400 |
| 19 | 管理员关闭用途公开能力 | 该用途 public 文件转 private，匿名访问立即失效 |

## 16. 风险与待确认

### 16.2 待确认
