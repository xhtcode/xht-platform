## 后端启动



> **启动前必须设置环境变量 `XHT_SECURITY_AUTH_VALUE`**（`xht-admin`、`xht-auth`、`xht-generate` 取同一个值）。
> 该变量是服务间内部接口（`/api/**`）的调用凭证，仓库内不保存明文；未设置时服务能正常启动，但 `@IgnoreAuth(aop = true)` 的内部接口会拒绝访问，表现为字典查询、操作日志上报、站内信发送等跨服务调用返回 403。
>
> IDE 中在 Run Configuration 的 Environment variables 里添加；命令行示例：`export XHT_SECURITY_AUTH_VALUE=<自定义值>`。

### 访问方式



| 入口        | 地址                            |
| :---------- | :------------------------------ |
| 网关        | `http://localhost:8080`         |
| 管理端 API  | `http://localhost:8080/admin/**` |
| 认证中心 API | `http://localhost:8080/auth/**`  |
| 代码生成 API | `http://localhost:8080/generate/**` |
| admin 直连  | `http://localhost:8081`         |
| auth 直连   | `http://localhost:9000`         |
| generate 直连 | `http://localhost:9700`       |

> 网关已关闭 `discovery.locator`，按服务名直连的 `/xht-admin/**`、`/xht-generate/**`、`/xht-auth/**` 不再可用。
>
> `/api/**` 是服务间内部接口，网关会统一拒绝（返回 404，不暴露接口是否存在），只能由 Feign 直连调用；判定基于**入站路径**（按命中路由的 `StripPrefix` 段数剥段后再归一化），因此 `%2e%2e`、`%252e%252e`、`//`、`;` 等变体同样返回 404。受保护根路径见 `xht.gateway.internal-api.roots`（默认 `/api`），**修改后需重启网关**；本地调试请走上面的显式前缀或直接访问服务端口。

# Liunx部署



## nginx配置文件



> 提醒： 如果不需要统一身份认证的话就不要配置授权服务器



```nginx
http {

    include mime.types;
    default_type application/octet-stream;
    sendfile on;
    keepalive_timeout 65;
    # ==============================================
    # 一、授权服务器集群（100台都在这里加）
    # ==============================================
    upstream auth_cluster {

        server 127.0.0.1:9000 weight=1;
        # 在这里加 10台、50台、100台 都可以
        ip_hash;
    }

    # ==============================================
    # 二、网关集群（业务接口）
    # ==============================================
    upstream gateway_cluster {

        server 127.0.0.1:8080 weight=1;
        # 在这里加 10台、50台、100台 都可以
        ip_hash;
    }


    server {

        listen 80;
        server_name localhost 你的域名;
        gzip on;
        gzip_min_length 1k;
        gzip_comp_level 4;
        gzip_proxied any;
        gzip_types text/plain text/xml text/css;
        gzip_vary on;
        gzip_disable "MSIE [1-6]\.(?!.*SV1)";

        location ^~/api/ {

            proxy_pass http://gateway_cluster;
            proxy_set_header Host $http_host;
            proxy_set_header REMOTE-HOST $remote_addr;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto http;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection "upgrade";
            proxy_set_header REMOTE-HOST $remote_addr;
        }

        location / {

            root /usr/local/nginx/html/admin;
            try_files $uri $uri/ /index.html;
            index index.html index.htm;
        }


        # 屏蔽所有敏感路径
        location ~* ^/(actuator|swagger-ui|v3/api-docs|swagger-resources|webjars|doc.html) {

            return 403; # 禁止访问
        }
        error_page 500 502 503 504 /50x.html;
        location = /50x.html {

            root html;
        }
    }


    server {

        listen 80;
        server_name localhost 你的域名;
        gzip on;
        gzip_min_length 1k;
        gzip_comp_level 4;
        gzip_proxied any;
        gzip_types text/plain text/xml text/css;
        gzip_vary on;
        gzip_disable "MSIE [1-6]\.(?!.*SV1)";

        location ^~/api/ {

            proxy_pass http://auth_cluster/;
            proxy_set_header Host $http_host;
            proxy_set_header REMOTE-HOST $remote_addr;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto http;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection "upgrade";
            proxy_set_header REMOTE-HOST $remote_addr;
        }
        location ^~/oauth2/ {

            proxy_pass http://auth_cluster;
            proxy_set_header Host $http_host;
            proxy_set_header REMOTE-HOST $remote_addr;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto http;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection "upgrade";
            proxy_set_header REMOTE-HOST $remote_addr;
        }
        location / {

            root /usr/local/nginx/html/iam;
            try_files $uri $uri/ /index.html;
            index index.html index.htm;
        }

    }

}
```
